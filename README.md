# 镇纸 Paperweight

一张常驻 macOS 桌面的宣纸卡片，随机显示《孙子兵法》《庄子》《墨子》《王阳明心学》《曾国藩家书》《毛泽东选集》里的句子，每条都配原文出处与白话释义。

六本书各有自己的纸色、书名字体和闲章——不看书名也知道是谁在说话。

![六本书的卡片预览](previews/sheet.png)

<sub>上排短句、下排长句，明暗主题各半。左起：孙子兵法 · 庄子 · 墨子 · 王阳明心学 · 曾国藩家书 · 毛泽东选集</sub>

## 安装

```bash
./build.sh && open 镇纸.app
```

需要 macOS 14+ 与 Xcode 命令行工具。构建产物 1.7 MB，纯 Swift，无第三方依赖。

首次打开若被 Gatekeeper 拦（ad-hoc 签名），在「系统设置 → 隐私与安全性」里放行一次即可。

## 用法

卡片常驻桌面，菜单栏有一个 `❝` 图标。

| 操作 | 行为 |
|---|---|
| 单击卡片 | 换下一句 |
| 拖动卡片 | 移动位置（自动记忆） |
| ⌥ 单击 | 收起 / 展开释义（默认展开）|
| ⌃⌥Space | 全局换一句（不需要辅助功能授权） |
| 点菜单栏图标 | 完整菜单 |

菜单里可调：**书目**（六本可任意组合）、**轮换间隔**（15 分钟 ~ 2 小时 / 不自动换，默认 45 分钟）、**排版**（横排 / 竖排 / 自动）、**正文字体**（宋 / 楷 / 仿宋 / 黑，五本书统一）、**外观**（跟随系统 / 浅色 / 深色）、**卡片宽度**、**窗口层级**（悬浮最上层 / 贴在桌面上）、收藏与只看收藏、开机自启。

**排版默认横排**。竖排好看，但要一个字一个字往下数，不是日常阅读习惯；想试的话在菜单 → 排版 → 竖排（短句会按断句分栏、去标点，是古籍本来的样子）。

## 语料

345 条，`Resources/corpus.json`。孙子 69 / 庄子 72 / 墨子 54 / 王阳明 56 / 毛选 57 / 曾国藩 37。

**收录标准**（宁少毋滥）：脱离上下文独立成立 · 能映射到今天的处境 · 语言有锋刃 · 不与已有条目语义重复。曾经收到过 400 条，按这套标准回头裁掉了 92 条——上下文依赖的残句（庄子「之二虫又何知」）、操作细则（孙子「车杂而乘之，卒善而养之」）、语义重复的近义条。裁掉的都留在 `archive-trimmed.json` 里，可随时取回。

只收能定位到原书的句子。

语料由模型知识写出，再逐条与维基文库公有领域底本做去标点全文比对，篇目归属以底本为准。**286/345 条通过原文 + 篇目校验**；其余 59 条（57 条毛选 + 2 条王阳明《年谱》）没有可检索的公有领域底本，在 JSON 里 `verified` 为 `null`，文本与出处**未经原书核对**。

校验抓到的问题、裁决过程和见证本清单见 [docs/product-design-2026-09-14.md](docs/product-design-2026-09-14.md) 第七节。

重跑校验：

```bash
python3 -m venv venv && ./venv/bin/pip install zhconv
./venv/bin/python scripts/fetch_sources.py && ./venv/bin/python scripts/verify2.py Resources/corpus.json
```

## 开发

```bash
./scripts/preview.sh ./previews   # 离屏渲染各书各排版的卡片 PNG，不需要录屏授权
```

自测（语料完整性、竖排切分、抽样器均匀性与间隔上界）随 `scripts/SelfTest.swift` 编译运行。

## 结构

曾国藩这一本是**反过来做的**：先抓《曾国藩家书》原文，再从原文里挑，而不是凭记忆写。原因是探测发现我记忆里的「曾国藩名言」有 35/46 在底本中找不到——「莫问收获，但问耕耘」「扎硬寨，打呆仗」这类流传极广的句子，很可能是后人托名或概括。他是被鸡汤工业污染最重的一位。（注意：底本只是维基文库的家书选本约 4.5 万字，日记、书札均无，所以「找不到」只能说明未获见证，不等于证伪。）
